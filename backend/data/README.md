# Replay Sample Dataset

`backend/data/replay_sample.csv` (gitignored) is a stratified 5,018-row sample extracted from `data/raw/` across all 8 CICIDS2017 flow files covering all 15 classes.

Label: "sample from raw data, not the teammate's test split".
This file is used for demo replay and sanity checks, not as a research or benchmark result.
